## 目标

通过 MCP 知识库查询或 Web 搜索，获取目标特性（华为防火墙设备）的典型用户应用场景，
以交互方式与用户对齐场景列表，输出场景文档作为后续 M/F 分析的输入。

## 适用范围

- 适用阶段：MFQ 分析的 scenario 阶段
- 输入：特性名称 + 基本描述（来自 feature-parser 输出）
- 输出：`.workflow-meta/mfq/scenarios/confirmed-scenarios.md`

## 前置条件

- [ ] feature-parser 已完成，`.workflow-meta/mfq/feature-input/` 目录存在
- [ ] 特性名称和基本描述已确定

## 搜索策略

按以下优先级获取场景信息：

```
1. MCP 知识库查询（首选）
   ↓ 未命中
2. Web 搜索（回退）
   ↓ 补充
3. 用户提供的材料
```

### MCP 知识库查询

调用 `scripts/mcp_query_client.py` 查询知识库：

```bash
python scripts/mcp_query_client.py --query "<特性名称> 应用场景" --type scenario
```

若 MCP 未配置或无结果，自动回退到 Web 搜索。

### Web 搜索

使用平台内置搜索能力（如可用），搜索关键词：
- `华为防火墙 <特性名称> 应用场景`
- `华为 NGFW <特性名称> 部署方案`
- `Huawei firewall <特性英文名> use case`

### 用户材料补充

用户可能在 feature-parser 阶段提供了应用场景文档，从中提取场景信息。

## 执行流程

### 步骤 1：信息收集

1. 读取 `.workflow-meta/mfq/feature-input/raw-requirements.md` 获取特性概况
2. 尝试 MCP 查询 → 无结果则 Web 搜索
3. 提取候选场景列表

### 步骤 2：场景结构化

将收集到的场景信息结构化为标准格式：

| 字段 | 说明 |
|------|------|
| 场景编号 | `SCN-<特性缩写>-NNN` |
| 场景名称 | 简明场景描述 |
| 场景分类 | 主场景 / 扩展场景 |
| 场景描述 | 详细的业务流程描述 |
| 触发条件 | 场景发生的前提条件 |
| 处理逻辑 | 主要处理步骤 |
| 异常路径 | 可能的异常情况 |
| 用户关注点 | 该场景下用户最关注的功能点 |
| 关联模块 | 涉及的四/五级目录模块 |

### 步骤 3：用户交互确认

以表格或列表形式展示候选场景，使用 `ask_user` 确认：

```
## 应用场景确认

特性：<特性名>

已发现 N 个典型场景：

| # | 场景名称 | 分类 | 关联模块 |
|---|---------|------|---------|
| 1 | ... | 主场景 | ... |
| 2 | ... | 扩展场景 | ... |

请确认场景列表，或指出需要修改/补充的场景。
```

用户可能的操作：
- 全部确认
- 修改某个场景的描述
- 新增场景
- 删除不适用的场景

### 步骤 4：输出持久化

将确认后的场景写入 `.workflow-meta/mfq/scenarios/confirmed-scenarios.md`：

```markdown
# <特性名> — 已确认应用场景

## 场景概览

| 编号 | 名称 | 分类 | 关联模块 |
|------|------|------|---------|
| SCN-XXX-001 | ... | 主场景 | ... |

---

## SCN-XXX-001: <场景名称>

**分类**：主场景

**场景描述**：
<详细描述>

**触发条件**：
- ...

**处理逻辑**：
1. ...
2. ...

**异常路径**：
- ...

**用户关注点**：
- ...

**关联模块**：
- 四级：...
- 五级：...
```

## Gotchas

- Web 搜索结果可能包含过时信息（旧版本特性），需标注版本适用性
- 华为产品文档常使用特定术语（如"安全域"、"安全策略"），需保留原始术语
- 不同型号（TGFW vs NGFW）的场景可能有差异，需与用户确认适用范围
- 场景过多时（> 10 个），建议分主场景/扩展场景两类，先确认主场景

## 验收标准

- [ ] 至少输出 1 个已确认的应用场景

- [ ] 场景关联到四/五级目录模块
- [ ] 用户已确认场景列表
- [ ] `confirmed-scenarios.md` 已写入 `.workflow-meta/mfq/scenarios/`
